# 🎨 Guía de Personalización: Estilo CSS en Jellyfin

  

Esta guía detalla los pasos para acceder al editor de estilos de **Jellyfin** y aplicar configuraciones personalizadas de CSS para mejorar la interfaz visual de nuestro servidor **OnlyUses**.

  

---

  

## 🛠️ Pasos para acceder a la configuración de estilo

  

### 1. Acceso al Perfil de Usuario

Para comenzar, dirígete a la parte superior derecha de la interfaz de Jellyfin y haz clic en el icono de tu **Usuario**.

**

**

### 2. Panel de Control de Administrador

Dentro del menú desplegable, selecciona la opción **Panel de Control**. Nota: Esta opción solo es visible para usuarios con privilegios de administrador.

**

<img width="722" height="669" alt="Pasted image 20260219154931" src="https://github.com/user-attachments/assets/2e66a98d-9372-44a8-9676-96015b60a694" />


**

### 3. Ajustes de Apariencia

En la barra lateral izquierda del Panel de Control, busca y selecciona el apartado **Apariencia**. Aquí se gestionan todos los temas y efectos visuales del servidor.

**

<img width="611" height="910" alt="Pasted image 20260219155722" src="https://github.com/user-attachments/assets/0405b0e5-bb6f-4ef2-a84c-0423ba7ba669" />

## 🖌️ Aplicar Código CSS Personalizado

  

Una vez dentro del menú de Apariencia, desplázate hasta la parte inferior donde encontrarás el cuadro de texto **Código CSS personalizado**. Aquí es donde podrás pegar los estilos para modificar el fondo o los colores de la interfaz.

**

<img width="669" height="591" alt="Pasted image 20260219155857" src="https://github.com/user-attachments/assets/5b7a1afe-9fc6-48b8-992c-5f2acde72c9b" />



**

### 💡 Tips de OnlyUses para equipos ligeros:

* **Temas sencillos:** Evita efectos de desenfoque (*blur*) muy pesados si accedes desde equipos antiguos.

* **Previsualización:** Guarda los cambios y refresca tu navegador (F5) para ver los resultados aplicados instantáneamente.

  

---

> [!TIP]

> Puedes encontrar ejemplos de códigos CSS optimizados en nuestra carpeta de [config](../config).
